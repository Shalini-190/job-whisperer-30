# JobWhisperer AI Autofill Extension - Quick Start

## 🚀 Get Started in 5 Minutes

### 1. Prerequisites (2 minutes)
- ✅ **JobWhisperer AI Account**: Sign up at [JobWhisperer AI](https://hlewejtogcgwmfrtkqef.supabase.co)
- ✅ **Complete Profile**: Fill in your name, email, phone, location, and summary
- ✅ **Generate AI Answers**: Create answers for common interview questions

### 2. Install Extension (1 minute)
1. **Open Chrome/Edge** and go to `chrome://extensions/` or `edge://extensions/`
2. **Enable Developer Mode** (toggle in top-right)
3. **Click "Load unpacked"** and select the `extension` folder
4. **Pin the extension** to your toolbar

### 3. Test the Extension (2 minutes)
1. **Open the test form**: Open `extension/test-form.html` in your browser
2. **Click the extension icon** - you should see a green dot and your name
3. **Click "🚀 Autofill Application"** - watch the form fill automatically!
4. **Check the console** (F12) for "JobWhisperer AI Autofill" messages

## 🎯 Ready to Use!

The extension will now work on:
- **Greenhouse** job applications
- **Lever** job applications  
- **Any job application form** (generic detection)

## 🔧 Troubleshooting

### Red dot in extension popup?
- You're not logged into JobWhisperer AI
- Go to [JobWhisperer AI](https://hlewejtogcgwmfrtkqef.supabase.co) and log in
- Refresh the extension popup

### No forms detected?
- Make sure you're on an actual job application page
- Some forms load dynamically - wait a few seconds
- Try refreshing the page

### Fields not filling?
- Check that your JobWhisperer AI profile is complete
- Check browser console (F12) for error messages
- Try the test form first to verify everything works
